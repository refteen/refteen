# Скриншоты кейса DerevnyaMap

Файлы, которые показываются в модалке «Смотреть кейс» на карточке проекта:

| Файл           | Что на скриншоте                                       |
|----------------|--------------------------------------------------------|
| `map.jpg`      | Карта мест: кластеры и карточка объекта прямо на карте  |
| `listing.jpg`  | Страница объекта: фото, рейтинг, цена за сутки          |
| `booking.jpg`  | Бронирование: даты, гости, живой расчёт стоимости       |
| `account.jpg`  | Кабинет владельца: тариф, объекты, избранное, отзывы    |

Чтобы заменить — просто положи файл с тем же именем поверх старого,
код менять не нужно. Ширина 1600 px, JPEG q90.

На `map`, `listing` и `booking` в кадр попала плашка браузера
«Чтобы выйти из полноэкранного режима…» — если переснимешь их
не в полноэкранном режиме (F11), станет чище.

Если файла нет, на его месте показывается пунктирный слот с подсказкой —
сайт из-за этого не ломается.
